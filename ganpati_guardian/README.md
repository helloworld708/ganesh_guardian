# 🙏 Ganpati: The Festival Guardian 🌸

A fast-paced, visually vibrant browser game created for the **Ganesh Chaturthi Game Design Contest**. Help Lord Ganesha collect sacred offerings and protect the festive spirit!

![Game Preview](https://via.placeholder.com/800x400?text=Ganpati+The+Festival+Guardian+Gameplay) <!-- Replace with actual screenshot later -->

## 🌟 Overview
**Ganpati: The Festival Guardian** is a casual action game where the player guides a stylized Ganesha character through a bustling festive environment. The goal is to collect traditional offerings (Modaks, Flowers, Diyas) to gather "Blessing Points" while navigating through crowded festival streets and avoiding obstacles.

The game is designed to celebrate the joy, community, and traditions of Ganesh Chaturthi through engaging gameplay and a modern Indian aesthetic.

## 🚀 Features

### 🎮 Gameplay Mechanics
- **Dynamic Spawning**: Items and obstacles spawn in "waves," ranging from reward-heavy drops to challenging obstacle-dense corridors.
- **Combo System**: Collect items consecutively to increase your multiplier from **x1 up to x5**, drastically boosting your score.
- **Progressive Difficulty**: Three distinct levels:
    1. **The Celebration Begins**: A gentle introduction to the festive world.
    2. **The Festival Streets**: Increased speed and more crowded paths.
    3. **The Grand Celebration**: The high-speed climax with maximalist festive decorations.
- **Divine Power-ups**:
    - 🛡️ **Divine Blessing**: Temporary invincibility.
    - 💰 **Golden Modak**: Massive instant score boost.
    - ⚡ **Modak Power**: Instant combo multiplier increase.
    - 🔔 **Divine Bell**: Magnet effect that attracts nearby collectibles.

### 🎨 Visuals & Audio
- **Festive Palette**: Uses a traditional color scheme of Saffron, Gold, and Deep Maroon.
- **Juicy Effects**: Screen shake on impact, particle bursts of saffron petals on collection, and smooth bobbing animations.
- **Immersive Audio**: Festive sound effects (SFX) powered by the Web Audio API for low-latency feedback.

## 🛠️ Tech Stack
- **Language**: JavaScript (ES6+)
- **Rendering**: HTML5 Canvas API
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: CSS3 (Responsive Design)

## 📦 Installation & Setup

To run the game locally:

1. **Clone the repository**:
   ```bash
   git clone <your-repo-url>
   cd ganpati_guardian
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Play**: Open the local URL provided by Vite (usually `http://localhost:5173`) in your browser.

## 🕉️ Cultural Context
This game is built with deep respect for the traditions of Ganesh Chaturthi. It avoids any depiction of violence or disrespect toward the deity, focusing instead on the **positive energy**, **devotion**, and **community celebration** that define the festival.
